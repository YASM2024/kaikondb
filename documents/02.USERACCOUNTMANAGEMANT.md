## ユーザーアカウント管理 — 使い方ガイド

本ドキュメントは、Kaikon-DB における**ユーザー区分（権限）**とアカウントの使い方を説明します。未ログイン者・一般ユーザー・モデレーター・管理者それぞれの役割とできることを中心に解説します。

各機能の詳細な画面操作は、次のドキュメントを参照してください。

- [10.LITERATURES.md](10.LITERATURES.md) — 文献

- [12.SPECIMENS.md](12.SPECIMENS.md) — 標本
- [13.PHOTOS.md](13.PHOTOS.md) — 昆虫写真

## ユーザー区分の概要

Kaikon-DB では、利用者を次の 4 区分に分けて運用します。区分によって閲覧できる情報・登録・編集できるデータの範囲が異なります。


| 区分         | 概要                                             | ログイン |
| ---------- | ---------------------------------------------- | ---- |
| **未ログイン者** | オープンに公開されている情報を閲覧・検索できる                        | 不要   |
| **一般ユーザー** | 利用規定に同意のうえ登録し、個人利用の機能（プロフィール・写真投稿など）を使える       | 必要   |
| **モデレーター** | 担当区分の分類群に関するデータの品質・正確性に責任を持ち、文献・分布記録などを登録・編集する | 必要   |
| **管理者**    | プロジェクトオーナーとして、プロジェクト全体およびシステムに責任を持つ            | 必要   |


【ユーザー区分の関係イメージ】

1 人のアカウントに複数の区分を付与することも可能です（例：管理者が一般ユーザーとして写真を投稿する場合）。ただし、画面で実際に許可される操作は、**付与されている区分の組み合わせ**と**担当タグ**（モデレーター向け）によって決まります。

#### 未ログイン者

##### 役割

未ログイン者は、**オープンとなっている情報**を自由に利用できます。アカウント登録なしで、プロジェクトの公開データを閲覧・検索する主体です。

##### できること

- トップページ・拡張ページ（プロジェクト説明など）の閲覧
- 言語切替（日本語 / English）
- 各機能の**検索・詳細表示**（機能が有効な場合）
  - 文献検索・文献詳細
  - 分布情報（種検索・種詳細・科別種数 CSV）
  - 標本検索（公開設定の標本のみ）
  - 昆虫写真ギャラリー（**承認済み**写真のみ）

##### できないこと

- データの新規登録・編集・削除
- 写真の投稿
- 文献 PDF の閲覧（ログインが必要な場合あり）
- 管理者メニューへのアクセス
- マイページ（プロフィール編集）

【未ログイン時のナビゲーション・検索画面の画像】

#### 一般ユーザー

##### 役割

一般ユーザーは、利用規定のもと**アカウントを登録して利用する**利用者です。公開データの閲覧に加え、個人に紐づく機能（プロフィール管理・写真投稿など）を使えます。文献や分布記録の編集は行いません。

##### アカウントの取得

1. 画面上部メニューから「利用者登録」を開く
2. 名前・メールアドレス・パスワードを入力して登録する
3. 届いた認証メールのリンクを開き、メールアドレスを確認する
4. 認証完了後、一般ユーザーとして写真投稿などの機能が利用可能になる

【メール認証画面の画像】

登録直後はメール未認証のため、管理者メニューや写真投稿など認証が必要な機能は利用できません。認証が完了するまで、公開コンテンツの閲覧とマイページの一部操作にとどまります。

##### できること

- 未ログイン者と同様の、公開データの検索・閲覧
- マイページでのプロフィール編集（表示名・アイコン・自己紹介・メールアドレス）
- 昆虫写真の投稿・自分の写真の編集・削除（写真機能が有効な場合。投稿規程への同意が必要）
- ログイン状態に応じた追加表示（例：自分の未承認写真の表示、文献詳細での PDF 表示など）

##### できないこと

- 文献・分布記録・標本の登録・編集
- 写真の承認・取下げ
- 他ユーザーのデータの編集
- マスタデータの管理
- ユーザー権限・担当タグの変更

【マイページ・写真投稿画面の画像】

#### モデレーター

##### 役割

モデレーターは、管理者から割り当てられた**担当区分（分類群）**に関するデータの品質・正確性に責任を持つ利用者です。文献の登録・編集、分布記録の入力、写真の承認など、プロジェクトの中核データをメンテナンスします。

担当範囲は**担当タグ**で表現されます。例として「甲虫担当」「蝶蛾担当」「膜翅担当」など、目や分類群ごとに担当を分ける運用が想定されています。モデレーターは、**自分に付与された担当タグと一致する文献**に紐づくデータを中心に編集します。

【担当タグの割り当てイメージ】

##### 担当タグの考え方

- 管理者がユーザ管理画面で、モデレーターに 1 つ以上の担当タグを設定する
- 文献には、管理者が「担当タグ」を付与する（文献の編集画面・CSV 一括管理）
- モデレーターは、**自分の担当タグと文献の担当タグに共通点がある文献**のみ編集・PDF 操作・分布記録の編集・CSV 出力が可能
- 担当タグが文献に付いていない場合、モデレーターはその文献を操作できない

管理者はすべての文献・記録にアクセスできるため、担当タグの設定ミスや範囲外データは管理者が調整します。

##### できること

一般ユーザーの権限に加え、次が可能です（各機能が有効な場合）。


| 領域   | 主な操作                   | 範囲              |
| ---- | ---------------------- | --------------- |
| 文献   | 新規登録・編集・PDF 添付・CSV 入出力 | 担当タグ一致の文献       |
| 分布記録 | 新規登録・編集・削除・CSV ダウンロード  | 担当タグ一致の文献に紐づく記録 |
| 標本   | 新規登録                   | 全件（担当タグによる制限なし） |
| 昆虫写真 | 投稿承認・取下げ               | 承認待ち写真の管理       |
| マスタ  | 参照（目・科・種・市町村・雑誌・地点など）  | 閲覧・参照用画面        |
| 運用   | 履歴・統計の閲覧               | 各データ種別          |


管理者メニューから、文献データ管理・分布データ管理・標本情報管理・昆虫写真管理の各セクションにアクセスできます。

【管理者メニュー（モデレーター表示）の画像】

##### できないこと

- 文献の担当タグの変更（管理者のみ）
- 分類・市町村・雑誌などマスタの**編集・インポート**（管理者のみ）
- ユーザー権限・担当タグの付与（管理者のみ）
- 担当タグの一致しない文献・分布記録の編集

#### 管理者

##### 役割

管理者は**プロジェクトオーナー**であり、プロジェクトの全体およびシステムに責任を持つ利用者です。公開方針の決定、ユーザーと担当区分の割り当て、マスタデータの整備、データ品質の最終確認など、運営上の意思決定と実行を担います。

##### できること

モデレーターの権限に加え、次が可能です。

- **すべての文献・分布記録**へのフルアクセス（担当タグによる制限なし）
- 文献への**担当タグの設定・変更**
- **マスタ管理** — 分類（目・科・種）、市町村、雑誌、登録地点の登録・編集・CSV 入出力
- **ユーザー管理** — 区分の付与、担当タグ設定、アカウント有効/無効の切替
- 分布情報と写真機能が両方有効な場合、種詳細への**承認済み写真の紐付け**（最大 3 枚）
- 文献検索における件数制限の免除
- **拡張ページの管理** — プロジェクト説明・ご協力のお願いなど、サイト上の説明ページの作成・編集

##### 運用上の責任

- モデレーターの担当タグ割り当てと、文献への担当タグ付与
- マスタデータ（分類・地域・雑誌）の正確性の維持
- 不適切な投稿・データの是正（写真承認の判断を含む）
- 初期管理者アカウントのパスワード管理・メール認証

なお、システム内部には技術保守向けの区分もありますが、日常の運用では**管理者がこれらの作業も含めて担う**想定です。利用者向けの説明では、上記 4 区分を基準にしてください。

#### ログインとアカウント状態

##### ログイン

登録済みユーザーは、メールアドレスとパスワードでログインします。

【ログイン画面の画像】

##### メール認証

メールアドレスの確認が完了していないユーザーは、認証が必要な機能にアクセスできません。認証メールの再送は、認証案内画面から行えます。

##### アカウントの有効・無効

管理者はユーザ管理画面でアカウントの有効・無効を切り替えられます。無効化されたアカウントは運用ポリシーに従いログインできなくなります。

##### パスワード

ログイン後、パスワードの変更や「パスワードをお忘れですか？」による再設定が可能です。

#### 利用規定・同意

プロジェクト全体の利用条件は、拡張ページや法的情報（[80.LEGALINFORMATION.md](80.LEGALINFORMATION.md)）に記載されます。一般ユーザーは**利用規定に同意したうえで登録**し、利用します。

昆虫写真を投稿する際は、別途**投稿規程**への同意（画面のチェックボックス）が必要です。

サイト閲覧時の利用同意は、一部の画面で求められる場合があります。

#### 困ったときは


| 症状                  | 対処                                                                        |
| ------------------- | ------------------------------------------------------------------------- |
| 登録したが写真を投稿できない      | メール認証が完了しているか確認してください。一般ユーザーとして登録されているか管理者に確認してください。                      |
| 管理者メニューが空、または項目が少ない | モデレーター以上の区分が付与されているか、各機能が有効になっているか管理者に確認してください。                           |
| 文献・分布記録を編集できない      | モデレーターの場合、文献の担当タグが自分に割り当てられているか管理者に確認してください。                              |
| ログインできない            | メール認証・アカウント有効状態・パスワードを確認してください。登録・ログインが制限されている環境では、許可されたネットワークから接続してください。 |
| 権限を変更してほしい          | プロジェクト管理者に連絡し、必要な区分・担当タグの付与を依頼してください。                                     |
