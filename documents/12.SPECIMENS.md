<h2>標本（Specimens）— 使い方ガイド</h2>

<p>本ドキュメントは、Kaikon-DB の標本（Specimens）機能の使い方を説明します。前半の<strong>ユーザ編</strong>は画面操作の手順、後半の<strong>技術編</strong>は設定・データ構造など開発者向けの情報です。</p>

<p>標本機能は、県内などで採集された昆虫標本のラベル情報（採集地・採集日・同定情報など）を検索・閲覧する機能です。分布情報（<a href="11.INVENTORY.md">11.INVENTORY.md</a>）が文献に基づく地域記録を扱うのに対し、標本機能は個々の標本レコードを扱います。</p>

<hr>

<h2>ユーザ編</h2>

<h4 style="border-left:3em solid black;">標本機能とは</h4>

<p>標本機能では、採集ラベルや同定ラベルに記載された情報をもとに、昆虫標本を検索・閲覧できます。写真（最大 3 枚）や収蔵機関・保管番号なども、1 件の標本レコードとしてまとめて確認できます。</p>

<p>1 件の標本データ（レコード）には、主に次の情報が含まれます。</p>

<ul>
  <li><strong>同定情報</strong> — 和名・学名・性別・同定者</li>
  <li><strong>採集情報</strong> — 採集地・採集日（テキスト）・採集者・所有者</li>
  <li><strong>標本属性</strong> — タイプ標本区分・保存方法・収蔵機関・保管番号</li>
  <li><strong>位置情報</strong> — 緯度・経度（登録されている場合）</li>
  <li><strong>画像・ライセンス</strong> — 画像 URL（最大 3 枚）・利用ライセンス</li>
</ul>

<p>【標本機能の概要イメージ】</p>

<h4 style="border-left:3em solid black;">画面の開き方</h4>

<p>標本検索画面は、次のいずれかから開けます。</p>

<ul>
  <li>画面上部ナビゲーションの「標本検索」（メニュー名はプロジェクト設定により異なります）</li>
  <li>フッターの標本検索リンク</li>
</ul>

<p>【ナビゲーションから標本検索へ進む画面】</p>

<p>ログイン不要で検索・閲覧できます。標本データの登録には、モデレーター以上のアカウントでログインしてください。アカウントの種類については <a href="02.USERACCOUNTMANAGEMANT.md">02.USERACCOUNTMANAGEMANT.md</a> を参照してください。</p>

<h4 style="border-left:3em solid black;">標本を検索する</h4>

<p>標本検索画面を開くと、「検索」タブのフォームが表示されます。条件を入力して「検　　索」ボタンを押すと、該当する公開標本が一覧表示されます。</p>

<p>画面を開いた直後は、検索条件が未入力のため一覧は表示されません。いずれかの条件を入力して検索を実行してください。</p>

<p>検索条件は URL のクエリ文字列にも反映されるため、ブラウザの戻る・進む操作で検索状態を復元できます。</p>

<h2>技術編</h2>

<p>以下は、システム管理者・開発者向けの技術情報です。</p>

<h4 style="border-left:3em solid black;">標本（Specimens）機能</h4>

<p>Kaikon-DB の標本機能は、昆虫標本のラベル情報および関連メタデータを管理・検索するモジュールです。ライセンスマスタ（<code>licenses</code> テーブル）と連携し、公開フラグ（<code>is_public</code>）により検索結果への露出を制御します。</p>

<h4 style="border-left:3em solid black;">機能の有効化</h4>

<p><code>.env</code> に以下を設定すると標本機能が有効になります。</p>

<pre><code>SPECIMENS=1
</code></pre>

<p>設定値は <code>config/kaikon.php</code> の <code>SPECIMENS</code> キー経由で参照されます。<code>SPECIMENS=0</code>（デフォルト）の場合、ナビゲーション・ルート・管理者メニューから標本関連の項目は非表示になります。</p>

<h4 style="border-left:3em solid black;">標本検索 API</h4>

<p><strong>URL:</strong> <code>/specimens/search</code>（公開、レート制限 60/分）</p>

<table>
  <thead>
    <tr><th>パラメータ</th><th>説明</th></tr>
  </thead>
  <tbody>
    <tr><td><code>q</code></td><td>学名・和名・採集地の部分一致（OR）</td></tr>
    <tr><td><code>locality</code></td><td>採集地の部分一致</td></tr>
    <tr><td><code>collected_by</code></td><td>採集者の部分一致</td></tr>
    <tr><td><code>identified_by</code></td><td>同定者の部分一致</td></tr>
    <tr><td><code>owner</code></td><td>所有者の部分一致</td></tr>
    <tr><td><code>page</code></td><td>ページ番号</td></tr>
    <tr><td><code>per_page</code></td><td>1 ページあたり件数（デフォルト 12、最大 50）</td></tr>
  </tbody>
</table>

<p>レスポンスは Laravel ページネーション形式の JSON です。一覧表示用に <code>id</code>、<code>species</code>、<code>species_ja</code>、<code>locality</code>、<code>collection_date_text</code>、<code>collected_by</code>、<code>identified_by</code>、<code>image_1</code>、<code>license_name</code> を返します。</p>

<p><strong>注:</strong> 検索フォームには「採集日（テキスト）」欄（<code>name="date"</code>）がありますが、現時点のサーバー側（<code>SpecimenController::index</code>）では未処理です。</p>

<h4 style="border-left:3em solid black;">標本詳細 API</h4>

<p><strong>URL:</strong> <code>/specimens/{id}</code>（数値 ID、レート制限 60/分）</p>

<p>JSON で標本の全フィールドおよびライセンス名を返します。閲覧時に <code>specimens_history</code> へ <code>show</code> 履歴を記録します。</p>

<h4 style="border-left:3em solid black;">標本の登録</h4>

<p><strong>URL:</strong> <code>/specimens/create</code>（GET/POST、モデレーター以上）</p>

<p>GET で登録フォーム、POST で保存。<code>license_id</code> は必須。<code>is_public</code> はチェックボックス（未チェック時は false）。保存成功時は同一画面へリダイレクトし、フラッシュメッセージを表示します。</p>

<p>バリデーション概要:</p>

<ul>
  <li>緯度: -90 〜 90、経度: -180 〜 180</li>
  <li>文字列項目: 各カラムの max 長に準拠</li>
  <li><code>license_id</code>: <code>licenses</code> テーブルに存在する ID</li>
</ul>

<h4 style="border-left:3em solid black;">フロントエンド構成</h4>

<p>標本検索画面の JavaScript は <code>public/js/components/specimen/</code> 配下の ES モジュール群で構成されています。</p>

<table>
  <thead>
    <tr><th>ファイル</th><th>役割</th></tr>
  </thead>
  <tbody>
    <tr><td><code>index.js</code></td><td>初期化（モーダル bind、検索 init、URL パラメータからの自動検索）</td></tr>

<p>初回表示時、URL に検索クエリが含まれている場合のみ自動検索を実行します。条件が空の場合は一覧を描画しません。</p>
