<h2>分布情報（Inventory）— 使い方ガイド</h2>

<p>本ドキュメントは、Kaikon-DB の分布情報（Inventory）機能の使い方を説明します。前半の<strong>ユーザ編</strong>は画面操作の手順、後半の<strong>技術編</strong>は設定・データ構造など開発者向けの情報です。</p>

<p>分布情報は、文献に基づいて「どの昆虫種が、どの地域で報告・採集されたか」を整理・検索する機能です。文献機能（<a href="10.LITERATURES.md">10.LITERATURES.md</a>）と連携して利用します。</p>

<hr>

<h2>ユーザ編</h2>

<h4 style="border-left:3em solid black;">分布情報とは</h4>

<p>文献（論文・雑誌・図鑑など）に記載された昆虫の出現・採集情報を、種（和名・学名）単位でまとめて検索・閲覧できます。</p>

<p>1 件の分布データ（レコード）は、次の組み合わせで管理されます。</p>

<ul>
  <li><strong>種</strong> — 対象となる昆虫</li>
  <li><strong>文献</strong> — 情報の出典</li>
  <li><strong>市町村</strong> — 報告・採集された地域</li>
</ul>

<p>【分布情報の概要イメージ】</p>

<h4 style="border-left:3em solid black;">画面の開き方</h4>

<p>分布情報（種検索）画面は、次のいずれかから開けます。</p>

<ul>
  <li>画面上部ナビゲーションの「分布」（メニュー名はプロジェクト設定により異なります）</li>
  <li>トップページの分布情報セクション</li>
  <li>フッターの分布情報リンク</li>
</ul>

<p>【トップページから分布情報へ進む画面】</p>

<p>ログイン不要で検索・閲覧できます。分布データの登録・編集には、モデレーター以上のアカウントでログインしてください。</p>

<h4 style="border-left:3em solid black;">分類から種を探す</h4>

<p>分布情報画面を開くと、まず<strong>目（Order）</strong>ごとの種数一覧が表示されます。</p>

<p>【目一覧画面の画像】</p>

<p>目の行をクリックすると、その目に属する<strong>科（Family）</strong>一覧へ進みます。科をクリックすると、その科に記録がある<strong>種</strong>の一覧が表示されます。</p>

<p>【科一覧画面の画像】</p>
<p>【種一覧画面の画像】</p>

<p>画面上部の「戻る」リンクで、目一覧に戻れます。科一覧からは、目名をクリックして同じ目の科一覧に戻ることもできます。</p>

<h4 style="border-left:3em solid black;">キーワードで種を探す</h4>

<p>検索フォームの「キーワード」欄に、和名または学名の一部を入力し、「検　　索」ボタンを押します。</p>

<p>【キーワード検索の画像】</p>

<p>ヒットした種が一覧表示され、行をクリックすると詳細モーダルが開きます。該当がない場合は「該当はありませんでした」と表示されます。</p>

<h4 style="border-left:3em solid black;">目・科の種数一覧（CSV）</h4>

<p>分布情報画面の「目・科の種数一覧」リンクから、科ごとの記録種数を CSV でダウンロードできます。目・科の学名・和名と種数が含まれます。</p>

<p>【種数一覧ダウンロードリンクの画像】</p>

<h4 style="border-left:3em solid black;">種の詳細を見る</h4>

<p>種一覧またはキーワード検索結果から種名をクリックすると、詳細モーダルが開きます。</p>

<p>【種詳細モーダルの画像】</p>

<h5>表示される情報</h5>

<h5>地図の見方</h5>

<ul>
  <li><span style="color:#4db56a;">●</span> <strong>濃い緑</strong> — 採集記録に該当する地域（正式な記録）</li>
  <li><span style="color:#aaeeaa;">●</span> <strong>薄い緑</strong> — 採集記録を伴わない報告（参考情報）</li>
</ul>

<p>地図は記録の可視化であり、種の分布を正確に示すものではありません。モーダル下部の注記もご確認ください。</p>

<p>【分布地図の画像】</p>

<h5>分布情報の読み方</h5>

<p>分布情報欄には、採集記録に該当する地域が先に表示されます。参考情報（採集記録を伴わない報告）がある場合は「（参考：…）」として続けて表示されます。</p>

<p>地名の上付き数字（例：甲府市<sup>1)2)</sup>）は、関連文献リストの番号に対応します。</p>

<h4 style="border-left:3em solid black;">分布記録を登録する（モデレーター向け）</h4>

<p>モデレーター以上でログインすると、分布情報画面の「登録」タブ、または管理者メニュー（<code>/admin</code>）の「分布データ管理 → データ追加」から入力画面を開けます。</p>

<p>【登録タブ・管理者メニューの画像】</p>

<h5>手順</h5>

<ol>
  <li>種を選ぶ（目 → 科 → 種の順、またはキーワード検索）</li>
  <li>市町村を選ぶ（チェックボックス、複数選択可）</li>
  <li>「採集記録」または「その他」を選ぶ</li>
  <li>関連文献を指定する（文献 ID。文献の種リストから遷移した場合は自動入力）</li>
  <li>必要に応じて備考を入力する</li>
  <li>「確認」→ 内容確認 → 「確定」で保存</li>
</ol>

<p>【分布記録入力画面の画像】</p>
<p>【分布記録確認画面の画像】</p>
<p>【分布記録完了画面の画像】</p>

<h5>種の選び方</h5>

<p>新規登録時は、次の方法で種を指定します。</p>

<ul>
  <li><strong>分類から選ぶ</strong> — 目ボタン → 科ボタン → 種ボタンの順にクリック。パンくず風のボタンで選択をやり直せます</li>
  <li><strong>キーワード検索</strong> — 和名・学名の一部を入力して「検索」</li>
  <li><strong>種追加</strong> — マスタにない種は「種追加」リンクから分類マスタ画面を開き、管理者が種を登録</li>
</ul>

<p>【種選択 UI の画像】</p>

<h5>市町村の選び方</h5>

<p>「分布情報登録」欄に市町村のチェックボックスが並びます。</p>

<ul>
  <li>検索ボックスで市町村名を絞り込み</li>
  <li>「選択中のみ」でチェック済みの地域だけ表示</li>
  <li>「全解除」ですべての選択を解除</li>
  <li>「地点不明」を選ぶと、他の市町村の選択は自動的に解除されます</li>
</ul>

<p>【市町村選択 UI の画像】</p>

<h5>採集記録とその他</h5>

<table>
  <thead>
    <tr><th>選択</th><th>意味</th><th>地図上の表示</th></tr>
  </thead>

    <tr><td>採集記録</td><td>標本採集など、要件を満たす正式な記録</td><td>濃い緑（記録）</td></tr>
    <tr><td>その他</td><td>目撃・文献上の報告など、参考情報</td><td>薄い緑（参考）</td></tr>
  </tbody>

<p>同じ文献・同じ種について、1 回の登録操作で選んだ市町村は、すべて同じ「採集記録 / その他」の区分で保存されます。</p>

<h5>関連文献について</h5>

<p>分布記録には必ず出典文献が必要です。文献検索画面の種リスト「追加」から遷移した場合、文献情報が自動でセットされます。手動で登録する場合は文献 ID（数値）を入力します。</p>

<p>文献が「完了」（ロック）状態の場合、新規登録はできません（<a href="10.LITERATURES.md">10.LITERATURES.md</a> の「記録の完了」を参照）。</p>

<h4 style="border-left:3em solid black;">分布記録を編集・削除する（モデレーター向け）</h4>

<p>編集できるのは、関連文献の<strong>担当タグ</strong>が自身と一致するモデレーター、または管理者です。</p>

<h5>編集画面を開く方法</h5>

<ul>
  <li>種詳細モーダルの関連文献横にある鉛筆アイコン（ログイン時）</li>
  <li>文献の種リストから種名リンクをクリック</li>
</ul>

<p>【記録編集リンクの画像】</p>

<p>編集画面では種名は変更できません。市町村の選択・採集記録区分・備考を変更し、確認 → 確定で保存します。</p>

<p>「削除」ボタンで、当該文献×種の組み合わせに属するすべての市町村レコードを削除できます。文献がロックされている場合は編集・削除できません。</p>

<p>【分布記録編集画面の画像】</p>

<h4 style="border-left:3em solid black;">種への写真紐付け（管理者向け）</h4>

<p>写真機能（<code>PHOTOS=1</code>）が有効な場合、管理者は種詳細モーダルから承認済み写真を種に紐付けできます（最大 3 枚）。</p>

<p>【種写真管理 UI の画像】</p>

<ol>
  <li>種詳細モーダルを開く</li>
  <li>写真スロットの編集ボタンを押す</li>
  <li>キーワードで写真を検索し、スロットに割り当てる</li>
  <li>「写真を保存」で確定</li>
</ol>

<p>一般ユーザー・モデレーターには表示されません。写真の投稿・承認については <a href="13.PHOTOS.md">13.PHOTOS.md</a> を参照してください。</p>

  <li><strong>統計</strong> — 目別記録数、市町村別記録数、ユーザー別入力件数など</li>

<h2>技術編</h2>

<p>以下は、システム管理者・開発者向けの技術情報です。</p>

<h4 style="border-left:3em solid black;">分布情報（Inventory）機能</h4>

<p>Kaikon-DB の分布情報機能は、文献に基づく昆虫種の地域分布（レコード）を管理・検索するモジュールです。種マスタ・市町村マスタ・文献データと連携します。</p>

<h4 style="border-left:3em solid black;">機能の有効化</h4>

<p><code>.env</code> に以下を設定すると分布情報機能が有効になります。</p>

<pre><code>INVENTORY=1
</code></pre>

<p>文献機能（<code>LITERATURES=1</code>）と組み合わせる想定です。地図表示には <code>PPREFECTURE</code>（対象都道府県コード）の設定が必要です。</p>

<h4 style="border-left:3em solid black;">データモデル</h4>

<p>分布記録 1 件（<code>records</code> テーブルの 1 行）は、文献 × 種 × 市町村の組み合わせに対応します。</p>

<table>
  <thead>
    <tr><th>項目</th><th>説明</th></tr>
  </thead>
  <tbody>
    <tr><td><code>literature_id</code></td><td>出典文献（<code>literatures.id</code>）</td></tr>
    <tr><td><code>species_id</code></td><td>昆虫種（<code>speciess.id</code>）</td></tr>
    <tr><td><code>municipality_id</code></td><td>市町村（<code>municipalities.id</code>）</td></tr>
    <tr><td><code>is_collected</code></td><td>0=参考（その他）、1=採集記録</td></tr>
    <tr><td><code>memo</code></td><td>備考</td></tr>
    <tr><td><code>tag_id</code></td><td>担当タグ（種の目 ID 等。CSV 出力時のフィルタに使用）</td></tr>
    <tr><td><code>user_id</code></td><td>登録ユーザー</td></tr>
  </tbody>
</table>

<p>Web 画面では、同一文献 × 同一種について複数市町村を一括登録します。編集時は既存レコードを削除してから再作成します。</p>

<h4 style="border-left:3em solid black;">種検索 API</h4>

<p><strong>URL:</strong> <code>/species/search</code>（公開、レート制限 60/分）</p>

<table>
  <thead>
    <tr><th>パラメータ</th><th>説明</th></tr>
  </thead>
  <tbody>
    <tr><td><code>category=order</code> + <code>code={order_id}</code></td><td>目配下の科一覧</td></tr>
    <tr><td><code>category=family</code> + <code>code={family_code}</code></td><td>科配下の種一覧</td></tr>
    <tr><td><code>keyword={文字列}</code></td><td>和名・学名の部分一致</td></tr>
    <tr><td><code>page</code></td><td>ページ番号（25 件/ページ）</td></tr>
  </tbody>
</table>

<p>初回表示（<code>/species</code>）は目別種数をサーバー側で描画します。</p>

<h4 style="border-left:3em solid black;">種詳細 API</h4>

<p><strong>URL:</strong> <code>/species/{random_key}/show</code></p>

<p>JSON で種情報・文献別分布・写真（承認済み）を返します。閲覧時に <code>records_history</code> へ show 履歴を記録します。</p>

<p>文献ごとに <code>observations</code>（is_collected=0）と <code>collections</code>（is_collected=1）を分けて返します。フロントエンド側で採集記録と重複する参考情報を整理して表示します。</p>

<h4 style="border-left:3em solid black;">分布記録の CRUD</h4>

<h5>新規登録</h5>

<p><strong>URL:</strong> <code>/records/create</code>（GET/POST、モデレーター以上）</p>

<p>クエリ <code>?literature_id={id}</code> で文献を事前指定可能。入力 → 確認 → 完了の 3 ステップ。<code>verified=1</code> で確定保存。</p>

<h5>編集</h5>

<p><strong>URL:</strong> <code>/records/{literature_random_id}_{species_id}/edit</code></p>

<p>文献ロック中は HTTP 423。担当タグ不一致は HTTP 403。</p>

<h5>削除</h5>

<p>編集画面の DELETE、または POST <code>/records/{literature_species}/delete</code>。同一文献 × 種の全レコードを削除。</p>

<h5>文献ロック</h5>

<p><code>POST /records/complete</code> — 文献詳細モーダルから呼び出し。<code>recording_statuses</code> テーブルで管理。</p>

<h4 style="border-left:3em solid black;">種数サマリー CSV</h4>

<p><strong>URL:</strong> <code>/summary</code>（公開）</p>

<p>科別の記録種数を CSV 出力。カラム: order, order_ja, family, family_ja, count</p>

<h4 style="border-left:3em solid black;">記録 CSV ダウンロード</h4>

<p><strong>URL:</strong> <code>/records/download</code>（モデレーター以上）</p>

<p>カラム: id, literature_id, species_id, municipality_id, memo, user_id, created_at, updated_at, deleted_at, is_collected</p>

<h4 style="border-left:3em solid black;">CSV インポート</h4>

<p><code>/records/import</code> の画面は存在しますが、取込処理は未実装です（<code>import</code> メソッドはスタブ）。</p>

<h4 style="border-left:3em solid black;">種写真 API（管理者・PHOTOS=1）</h4>

<ul>
  <li><code>GET /species/photos/candidates</code> — 承認済み写真の検索</li>
  <li><code>POST /species/{random_key}/photos</code> — スロット 1〜3 への紐付け（<code>slot_1</code> … <code>slot_3</code>）</li>
</ul>

<h4 style="border-left:3em solid black;">履歴・統計</h4>

<ul>
  <li><strong>履歴:</strong> <code>/admin/history/records</code> — show / create / edit / delete を記録</li>
  <li><strong>統計:</strong> <code>/admin/statistics/records</code> — 目別記録数（上位 15）、市町村別（上位 15）、ユーザー別入力ランキング（上位 10）</li>
</ul>

<h4 style="border-left:3em solid black;">地図・ランドマーク</h4>

  <li><code>GET /landmarks</code> — 地図描画用ランドマーク JSON（公開）</li>
  <li>地点不明の市町村コード: <code>199900</code></li>
</ul>
