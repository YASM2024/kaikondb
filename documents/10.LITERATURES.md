<h2>文献情報（Literatures）— 使い方ガイド</h2>

<p>本ドキュメントは、Kaikon-DB の文献機能の使い方を説明します。前半の<strong>ユーザ編</strong>は画面操作の手順、後半の<strong>技術編</strong>は設定・データ構造など開発者向けの情報です。</p>

<hr>

<h2>ユーザ編</h2>

<h4 style="border-left:3em solid black;">文献機能とは</h4>

<p>文献機能では、昆虫に関する論文・雑誌・同好会誌・図鑑などの<strong>書誌情報</strong>を検索・閲覧できます。モデレーター以上の権限を持つユーザーは、文献の登録や PDF の添付、分布記録（どの種がどの地域で報告されたか）の入力も行えます。</p>

<p>【文献機能の概要イメージ】</p>

<h4 style="border-left:3em solid black;">画面の開き方</h4>

<p>文献検索画面は、次のいずれかから開けます。</p>

<ul>
  <li>画面上部のナビゲーション「文献」</li>
  <li>トップページの「文献検索」リンク</li>
  <li>フッターの「文献」リンク</li>
</ul>

<p>【トップページから文献検索へ進む画面】</p>

<p>ログイン不要で検索・閲覧できます。文献の登録や編集には、モデレーター以上のアカウントでログインしてください。アカウントの種類については <a href="02.USERACCOUNTMANAGEMANT.md">02.USERACCOUNTMANAGEMANT.md</a> を参照してください。</p>

<h4 style="border-left:3em solid black;">文献を検索する</h4>

<p>文献検索画面では、「検索」タブのフォームに条件を入力し、「検　　索」ボタンを押します。</p>

<p>【文献検索画面の画像】</p>

<table>
  <thead>
    <tr><th>入力項目</th><th>使い方</th></tr>
  </thead>
  <tbody>
    <tr><td>キーワード</td><td>表題、コメント、備考などに含まれる語句で探します。スペースで区切ると、すべての語句を含む文献に絞り込まれます。</td></tr>
    <tr><td>目</td><td>文献に関連付けられた昆虫の目（例：チョウ目、カブトムシ目）で絞り込みます。</td></tr>
    <tr><td>雑誌名</td><td>掲載誌の一覧から選択します。</td></tr>
    <tr><td>発行年</td><td>西暦 4 桁（例：2020）を入力します。</td></tr>
    <tr><td>著者</td><td>著者名の一部を入力します。日本語・英語表記のどちらにもマッチします。</td></tr>
  </tbody>
</table>

<p>複数の条件を入力した場合、すべての条件を満たす文献が表示されます（AND 検索）。「取り消し」ボタンで入力内容をクリアできます。</p>

<p>検索結果は、発行年の新しい順に並びます。件数が多い場合は「次のページ」ボタンで続きを読み込めます。</p>

<p>【検索結果一覧の画像】</p>

<h5>検索結果の見方</h5>

<p>各文献には、表題の下に著者・発行年・雑誌名などの概要（書誌情報の短い要約）が表示されます。表題をクリックすると、詳細情報のポップアップ（モーダル）が開きます。</p>

<p>ログインしている場合、表題の横に次のバッジが付くことがあります。</p>

<ul>
  <li><strong>PDF</strong>（赤）— 文献の PDF ファイルが登録されている</li>
  <li><strong>Inventory</strong>（灰）— 分布記録（種・地域のデータ）が登録されている</li>
</ul>

<p>検索結果が 100 件を超える場合（管理者を除く）、「ヒット件数が 100 件を超えました」と表示され、一覧は出ません。キーワードや発行年などを追加して、条件を絞り込んでください。</p>

<p>【100件超過メッセージの画像】</p>

<h4 style="border-left:3em solid black;">文献の詳細を見る</h4>

<p>検索結果の表題をクリックすると、詳細モーダルが開きます。</p>

<p>【文献詳細モーダルの画像】</p>

<p>モーダルには次の情報が表示されます。</p>

<ul>
  <li>著者、発行年、雑誌名、巻号、頁</li>
  <li>カテゴリ（文献に関連付けられた目）</li>
  <li>リンク（外部 URL が登録されている場合）</li>
  <li>コメント</li>
  <li>登録日、登録者（ログイン時）</li>
</ul>

<p>ログインしている場合は、PDF ファイルへのリンクや「種データ」関連のボタンも表示されます（後述）。</p>

<p>画面右上の言語切替（日本語 / English）により、著者名・表題・雑誌名の表示言語が切り替わります。</p>

<h4 style="border-left:3em solid black;">文献を登録する（モデレーター向け）</h4>

<p>モデレーター以上でログインすると、文献検索画面のタブに「登録」が表示されます。管理者メニュー（<code>/admin</code>）の「文献データ管理 → データ追加」からも同じ画面を開けます。</p>

<p>【登録タブ・管理者メニューの画像】</p>

<h5>手順</h5>

<ol>
  <li>「登録」タブ（または管理者メニュー）から文献追加画面を開く</li>
  <li>必要な項目を入力する（赤いラベルが付いた項目は必須）</li>
  <li>画面下の「確認」ボタンを押す</li>
  <li>確認画面の内容を見直し、「確定」ボタンで登録する</li>
</ol>

<h4 style="border-left:3em solid black;">文献を編集する（モデレーター向け）</h4>

<p>編集できるのは、自身の<strong>担当タグ</strong>が付いた文献、または管理者がすべての文献を編集できます。</p>

<p>編集画面への入り方は次の 2 通りです。</p>

<ul>
  <li>文献詳細モーダルの表題横にある鉛筆アイコン（ログイン時）</li>
  <li>検索結果の編集リンク（ログイン時）</li>
</ul>

<p>【編集アイコンの画像】</p>

<p>編集画面は登録時と同じ項目構成です。入力 → 確認 → 確定の流れで保存します。</p>

<p>【文献編集画面の画像】</p>

<h5>担当タグ（管理者のみ）</h5>

<p>管理者が文献を編集する場合、「担当タグ」にチェックを入れて、どのモデレーターがその文献を管理するかを指定できます。モデレーターは、自分と同じ担当タグの文献だけ編集できます。</p>

<p>【担当タグ設定の画像】</p>

<h5>文献の削除について</h5>

<p>画面からの削除は、確認画面まで用意されていますが、確定処理は未実装です。文献を削除する必要がある場合は、後述の「CSV 一括管理」で行ってください。</p>

<h4 style="border-left:3em solid black;">PDF を添付する（モデレーター向け）</h4>

<p>文献の編集画面では、PDF ファイルをアップロードできます（新規登録直後は、一度編集画面を開いてから添付します）。</p>

<p>【PDF アップロード欄の画像】</p>

<ul>
  <li>形式：PDF のみ</li>
  <li>サイズ：最大 50 MB</li>
  <li>アップロード後、表示名（短いラベル）を変更できます</li>
  <li>不要になった PDF は「削除」リンクで取り除けます</li>
</ul>

<p>PDF が登録された文献は、検索結果に PDF バッジが付き、詳細モーダルからファイルを開けます。</p>

<p>【詳細モーダルの PDF リンクの画像】</p>

<h4 style="border-left:3em solid black;">分布記録（種データ）との連携（モデレーター向け）</h4>

<p>文献は、昆虫の分布記録の「出典」として使われます。1 つの文献に対して、複数の種・市区町村の組み合わせを登録できます（分布記録機能の詳細は <a href="11.INVENTORY.md">11.INVENTORY.md</a> を参照）。</p>

<h5>種リストを見る</h5>

<p>文献詳細モーダルの「リスト」ボタンを押すと、その文献に登録されている種の一覧が開きます。目・科ごとに整理され、種名をクリックすると分布記録の編集画面へ進めます。</p>

<p>【種リスト画面の画像】</p>

<h5>分布記録を追加する</h5>

<p>種リスト画面の下部「追加」リンク、または分布記録の新規入力画面から、文献 ID を指定して記録を追加します。文献がロックされている場合は追加できません。</p>

<h5>記録の完了（ロック）</h5>

<p>文献に対する分布記録の入力が終わったら、詳細モーダルの「完了」ボタンを押してロックします。ロック中は、その文献への新規記録の作成・編集ができなくなります。</p>

<p>【完了・ロック解除ボタンの画像】</p>

<p>修正が必要になった場合は「ロック解除」で再び編集可能に戻せます。</p>

<h4 style="border-left:3em solid black;">CSV 一括管理（モデレーター向け）</h4>

<p>多数の文献をまとめて登録・更新・削除する場合は、管理者メニューの「文献データ管理 → データ一括管理」を使います。</p>

<p>【文献 CSV 一括管理画面の画像】</p>

<h5>エクスポート（ダウンロード）</h5>

<p>「CSVエクスポート」ボタンで、担当範囲内の文献データを CSV ファイルとして保存できます。バックアップや表計算ソフトでの確認に使えます。</p>

<h5>インポート（アップロード）</h5>

<ol>
  <li>「取込フォーマット（.csv）」リンクから雛形をダウンロードする</li>
  <li>Excel 等でデータを入力する（文字コード UTF-8、改行 LF、カンマ区切り、各項目は二重引用符で囲む）</li>
  <li>「CSVインポート」ボタンでファイルを選択する</li>
</ol>

<p>CSV の 1 行ごとに、次のように処理されます。</p>

<ul>
  <li><code>id</code> が空 → 新規追加</li>
  <li><code>id</code> あり・<code>delete_flg</code> が 1 → 削除</li>
  <li><code>id</code> あり・<code>delete_flg</code> が空または 0 → 更新</li>
</ul>

<p>【CSV 取込フォーマットの画像】</p>

<h5>データチェック</h5>

<p>「チェック実行」ボタンで、著者・発行年・表題・雑誌が同一の文献（重複の疑い）を CSV で出力できます。大量登録の前後に実行すると安心です。</p>

<h4 style="border-left:3em solid black;">履歴・統計（モデレーター向け）</h4>

<p>管理者メニューの「文献データ管理」から、次の画面を開けます。</p>

<ul>
  <li><strong>履歴</strong> — 文献の閲覧・登録・編集・削除の記録</li>
  <li><strong>統計</strong> — 雑誌別の文献件数ランキング</li>
</ul>

<p>【文献履歴画面の画像】</p>

<h2>技術編</h2>

<p>以下は、システム管理者・開発者向けの技術情報です。</p>

<h4 style="border-left:3em solid black;">機能の有効化</h4>

`.env` に以下を設定すると文献機能が有効になります。

<pre><code>LITERATURES=1
</code></pre>

`0` または未設定の場合、文献関連のルート・メニューは表示されません。分布記録（`INVENTORY=1`）と組み合わせて利用する想定です。

<h4 style="border-left:3em solid black;">文献検索</h4>

<p><strong>URL:</strong> <code>/literatures</code></p>

<p>ログイン不要で利用できます（JavaScript 必須）。次の条件で AND 検索します。</p>

<ul>
  <li><strong>キーワード</strong> — 表題（日英）、コメント、備考（memo1）。スペース区切りで複数指定可（すべて含む）</li>
  <li><strong>目（Order）</strong> — 文献に紐づく目で絞り込み</li>
  <li><strong>雑誌名</strong> — `journals` マスタから選択</li>
  <li><strong>発行年</strong> — 完全一致</li>
  <li><strong>著者</strong> — 日本語・英語表記の部分一致</li>
</ul>

<p>検索結果は発行年（降順）→ 雑誌 → 巻号 → 頁の順で並びます。未ログインまたは一般ユーザーの場合、ヒット件数が 100 件を超えると結果は表示されず「件数が多すぎます」と案内されます（管理者は制限なし）。</p>

<p>ログイン済みユーザーには、各文献について次のバッジが表示されます。</p>

<ul>
  <li><strong>PDF</strong> — 文献ファイル（`documents`）が登録されている</li>
  <li><strong>記録</strong> — 分布記録（`records`）が登録されている</li>
</ul>

<p>言語切替（`/lang/ja`・`/lang/en`）に応じて、著者・表題・雑誌名の表示言語が切り替わります。</p>

<h4 style="border-left:3em solid black;">文献の登録・編集・削除</h4>

<h5>新規登録</h5>

<p><strong>URL:</strong> <code>/literatures/create</code>（モデレーター以上）</p>

<p>入力 → 確認画面 → 完了画面の 3 ステップで登録します。確認画面で「登録する」を押すと `verified=1` が送信され、DB に保存されます。</p>

<h5>編集</h5>

<p><strong>URL:</strong> <code>/literatures/{random_id}/edit</code></p>

<p>検索結果モーダルの編集アイコン、または文献詳細から遷移できます。担当タグが一致するモデレーター、または管理者のみ編集可能です。</p>

<p>管理者のみ、編集画面で文献の<strong>担当タグ</strong>を変更できます。</p>

<h5>削除</h5>

<p>Web 画面からの削除（<code>/literatures/{random_id}/delete</code>）は確認画面まで実装済みですが、実行処理は未実装です。削除が必要な場合は CSV 一括管理（後述）の <code>delete_flg=1</code> を利用してください。</p>

<h4 style="border-left:3em solid black;">PDF 文献ファイルの管理</h4>

<p>文献編集画面から PDF をアップロードできます。</p>

<ul>
  <li>形式: PDF のみ</li>
  <li>上限: 50 MB（51200 KB）</li>
  <li>保存先: <code>storage/app/documents/</code></li>
  <li>表示名: アップロード後に編集可能（最大 10 文字）</li>
</ul>

<p>ログイン済みユーザーは文献詳細モーダルから PDF を開けます。モデレーターは担当タグに一致する文献の PDF のみ操作できます。</p>

<h4 style="border-left:3em solid black;">分布記録（レコード）との連携</h4>

<p>文献は分布記録の「出典」として機能します。1 文献に対し、種 × 市区町村の組み合わせで複数レコードを登録できます。</p>

<ul>
  <li><strong>記録入力:</strong> <code>/records/create?literature_id={id}</code></li>
  <li><strong>種リスト:</strong> <code>/literatures/{random_id}/species</code> — 当該文献に登録された種の一覧</li>
  <li><strong>記録編集:</strong> <code>/records/{random_id}_{species_id}/edit</code></li>
</ul>

<h5>文献ロック（記録完了）</h5>

<p>文献詳細モーダルの「完了」ボタンで、当該文献への分布記録入力をロックできます。ロック中は新規記録の作成・編集ができません（HTTP 423）。「ロック解除」で再度編集可能になります。</p>

<p>ロック状態は `recording_statuses` テーブルで管理されます。</p>

<h4 style="border-left:3em solid black;">CSV 一括管理</h4>

<p><strong>URL:</strong> <code>/admin/literatures/io</code>（モデレーター以上）</p>

<h5>エクスポート</h5>

<p>担当範囲内の文献を CSV でダウンロードします。全カラム（`memo1`〜`memo10` 含む）が出力されます。</p>

<h5>インポート</h5>

<p>取込フォーマット（16 項目）をダウンロードし、UTF-8・LF・カンマ区切り・二重引用符囲みの CSV をアップロードします。列順は任意です。</p>

<table>
  <thead>
    <tr><th>カラム</th><th>説明</th></tr>
  </thead>
  <tbody>
    <tr><td><code>id</code></td><td>更新・削除時に指定。新規追加時は空</td></tr>
    <tr><td><code>delete_flg</code></td><td>1 で論理削除（`id` 必須）</td></tr>
    <tr><td><code>author</code></td><td>著者（必須）</td></tr>
    <tr><td><code>author_en</code></td><td>著者（英語）</td></tr>
    <tr><td><code>year</code></td><td>発行年（必須、1000〜2050）</td></tr>
    <tr><td><code>title</code></td><td>表題（必須）</td></tr>
    <tr><td><code>title_en</code></td><td>表題（英語）</td></tr>
    <tr><td><code>language_id</code></td><td>1 / 2 / 9（必須）</td></tr>
    <tr><td><code>journal_code</code></td><td>雑誌コード（必須）</td></tr>
    <tr><td><code>publisher</code></td><td>出版者</td></tr>
    <tr><td><code>vol_no</code></td><td>巻号数</td></tr>
    <tr><td><code>page</code></td><td>頁数</td></tr>
    <tr><td><code>order_ids</code></td><td>目 ID をセミコロン区切り（例: <code>3;7</code>、1 件以上必須）</td></tr>
    <tr><td><code>link</code></td><td>外部リンク</td></tr>
    <tr><td><code>comment</code></td><td>コメント</td></tr>
    <tr><td><code>memo1</code></td><td>備考</td></tr>
  </tbody>
</table>

<p>行ごとに追加・更新・削除を判定します。担当タグのない文献はモデレーターが操作できずエラーになります。</p>

<h5>データチェック</h5>

<p>「文献重複チェック」を実行すると、著者・発行年・表題・雑誌が同一の文献グループを CSV で出力します。</p>

<h4 style="border-left:3em solid black;">履歴・統計</h4>

<ul>
  <li><strong>閲覧履歴:</strong> <code>/admin/history/literatures</code> — 文献詳細の表示（show）および CRUD 操作を記録</li>
  <li><strong>統計:</strong> <code>/admin/statistics/literatures</code> — 雑誌別の文献件数ランキング（上位 15 件）</li>
</ul>

<p>いずれもモデレーター以上が利用できます。</p>

<h4 style="border-left:3em solid black;">定期ジョブ</h4>

<p><code>UpdateLiteratureTitlesAndAuthors</code> ジョブがスケジュール実行され、英語表記が空の文献に対して次を自動補完します。</p>

<ul>
  <li><code>title_en</code> ← <code>title</code></li>
  <li><code>author_en</code> ← <code>author</code></li>
</ul>

<p>有効条件: <code>LITERATURES=1</code> かつ <code>KAIKON_JOB_LITERATURE_RECORDS_COMPLETION=1</code>（デフォルト有効）</p>
