<h2>昆虫写真（Photos）— 使い方ガイド</h2>

<p>本ドキュメントは、Kaikon-DB の昆虫写真機能の使い方を説明します。前半の<strong>ユーザ編</strong>は画面操作の手順、後半の<strong>技術編</strong>は設定・データ構造など開発者向けの情報です。</p>

<p>昆虫写真機能は、地域で撮影された昆虫の写真をギャラリー形式で公開・検索するモジュールです。分布情報（<a href="11.INVENTORY.md">11.INVENTORY.md</a>）と連携し、承認済み写真を種の詳細画面に表示できます。</p>

<hr>

<h2>ユーザ編</h2>

<h4 style="border-left:3em solid black;">昆虫写真機能とは</h4>

<p>ユーザーが撮影した昆虫の写真を投稿し、モデレーターの承認後に一般公開されます。種名・撮影場所・撮影日などの情報とともに、サムネイル一覧で閲覧できます。</p>

<p>著作権は撮影者に帰属します。無断転用は禁止です（画面にも同趣旨の注意書きが表示されます）。</p>

<p>【昆虫写真ギャラリーの概要イメージ】</p>

<h4 style="border-left:3em solid black;">画面の開き方</h4>

<p>昆虫写真画面は、次のいずれかから開けます。</p>

<ul>
  <li>画面上部ナビゲーションの「写真」（メニュー名はプロジェクト設定により異なります）</li>
  <li>トップページの写真セクション</li>
  <li>フッターの写真リンク</li>
</ul>

<p>ログイン済みの場合、ナビゲーションから自分の投稿一覧（投稿者フィルタ付き）へ直接進むリンクになることがあります。</p>

<p>【トップページから写真ギャラリーへ進む画面】</p>

<h4 style="border-left:3em solid black;">写真を検索・閲覧する</h4>

<p>「検索」タブのフォームに条件を入力し、「検索」ボタンを押します。条件未入力の場合は、承認済み写真（ログイン時は自分の未承認写真も含む）が新しい順に表示されます。</p>

<p>【写真検索画面の画像】</p>

<table>
  <thead>
    <tr><th>入力項目</th><th>使い方</th></tr>
  </thead>
  <tbody>
    <tr><td>キーワード</td><td>種名（photo_title）やコメント（memo）に含まれる語句。スペース区切りで複数指定可（すべて含む）</td></tr>
    <tr><td>採集地</td><td>撮影場所の部分一致（例：甲府市、北岳）</td></tr>
    <tr><td>採集日（テキスト）</td><td>撮影日文字列の部分一致（例：2025、2025-06）</td></tr>
    <tr><td>投稿者（撮影者）</td><td>プルダウンから特定の投稿者に絞り込み</td></tr>
  </tbody>
</table>

<p>「クリア」ボタンで入力をリセットし、再検索できます。結果は 12 件ずつ表示され、「続きを表示する」で次のページを読み込みます。</p>

<h4 style="border-left:3em solid black;">写真の詳細を見る</h4>

<p>サムネイルをクリックすると、詳細モーダルが開きます。</p>

<p>【写真詳細モーダルの画像】</p>

<ul>
  <li>拡大画像</li>
  <li>種名（タイトル）</li>
  <li>撮影者（アイコン・表示名。クリックでプロフィールモーダル）</li>
  <li>撮影場所・撮影日</li>
  <li>コメント</li>
</ul>

<p>ログインして自分の写真を開いた場合、右上に「承認待ち」または「公開中」のバッジが表示されます。自分の写真のみ、編集・削除アイコンが表示されます。</p>

<p>【承認待ち・公開中バッジの画像】</p>

<h5>撮影者プロフィール</h5>

<p>詳細モーダル内の撮影者名をクリックすると、プロフィールモーダルが開きます。アイコンと自己紹介文を確認できます。「戻る」で写真詳細に戻れます。</p>

<p>【撮影者プロフィールモーダルの画像】</p>

<h4 style="border-left:3em solid black;">写真を投稿する（ログインユーザー向け）</h4>

<p>ログインかつメール認証済み（<code>verified</code>）のアカウントで投稿できます。未ログイン時は「投稿」タブが無効です。</p>

<h5>手順</h5>

<ol>
  <li>「投稿」タブをクリック（投稿用モーダルが開く）</li>
  <li>画像エリアをクリックし、ファイルを選択する</li>
  <li>種名・撮影場所・撮影日・コメントを入力する</li>
  <li>投稿規程を読み、「規程に同意する」にチェックを入れる</li>
  <li>「確定」ボタンで送信する</li>
</ol>

<p>【写真投稿モーダルの画像】</p>

<h5>画像の要件</h5>

<ul>
  <li>形式：jpg、png、bmp</li>
  <li>サイズ：最大 2 MB</li>
  <li>内容：昆虫に関する画像（AI 生成・アダルト・セールス目的は不可）</li>
</ul>

<p>アップロード後、システムが自動的にリサイズします（表示用 800 px 幅、サムネイル 200 px 幅）。投稿直後は<strong>承認待ち</strong>状態であり、一般公開されません。管理者に通知メールが送信されます。</p>

<p>投稿成功後、「投稿されました。承認をお待ちください。」と表示され、ギャラリー画面に戻ります。</p>

<h5>投稿規程（画面表示の要点）</h5>

<ul>
  <li>他人が撮影した画像を無断で投稿しない</li>
  <li>昆虫に関する画像のみ</li>
  <li>撮影場所は原則市町村まで（希少種は詳細地点不可）</li>
</ul>

<h4 style="border-left:3em solid black;">自分の写真を編集・削除する</h4>

<p>自分が投稿した写真の詳細モーダルから、鉛筆アイコン（編集）またはゴミ箱アイコン（削除）を使えます。</p>

<p>【編集・削除アイコンの画像】</p>

<h5>編集</h5>

<p>編集モーダルで種名・撮影場所・撮影日・コメントを変更し「確定」します。画像ファイル自体の差し替えは、現状の Web UI ではできません（削除して再投稿）。</p>

<p>【写真編集モーダルの画像】</p>

<h5>削除</h5>

<p>削除を選ぶと確認ダイアログが表示されます。確定すると写真データとファイルが削除され、種への紐付けも解除されます。</p>

<h4 style="border-left:3em solid black;">写真の承認・取下げ（モデレーター向け）</h4>

<p>モデレーター以上は、管理者メニューの「昆虫写真管理 → 投稿承認・取下げ」から承認作業を行います。</p>

<p>【管理者メニューの写真管理リンクの画像】</p>

<p><strong>URL:</strong> <code>/photos/admin</code></p>

<h5>承認待ちタブ</h5>

<p>未承認の投稿が一覧表示されます。各行の「承認」ボタンを押すと公開状態になり、一般ユーザーも閲覧できるようになります。</p>

<p>【承認待ち一覧の画像】</p>

<h5>公開中タブ</h5>

<p>承認済みの写真一覧です。「取消」ボタンで承認を取り消し、再び非公開（承認待ち）に戻せます。</p>

<p>【公開中一覧の画像】</p>

<h5>管理画面の検索・並び替え</h5>

<p>投稿者名・種名・市町村・投稿日・撮影日で絞り込めます。表見出しをクリックすると、種名・投稿者・投稿日時・承認日時で昇順/降順に並び替えられます。24 件ずつページングされ、「続きを表示する」で追加読み込みします。</p>

<p>「規程同意」列には、投稿時に規程へ同意した日時（<code>agreed_at</code>）が表示されます。</p>

<h4 style="border-left:3em solid black;">メタデータのダウンロード</h4>

<p>管理者メニュー「昆虫写真管理 → メタデータダウンロード」から、写真のメタ情報を CSV で取得できます。</p>

<ul>
  <li>管理者 — すべての写真</li>
  <li>一般ログインユーザー — 自分の投稿のみ</li>
</ul>

<p>CSV には id、種名、撮影日、場所、投稿者、コメント、作成日時などが含まれます（画像ファイル本体は含みません）。</p>

<h4 style="border-left:3em solid black;">種への写真紐付け（管理者向け）</h4>

<p>分布情報（Inventory）が有効な場合、管理者は種詳細モーダルから承認済み写真を種に紐付けできます（最大 3 枚）。手順の詳細は <a href="11.INVENTORY.md">11.INVENTORY.md</a> の「種への写真紐付け」を参照してください。</p>

<h4 style="border-left:3em solid black;">履歴・統計（モデレーター向け）</h4>

<p>管理者メニューの「昆虫写真管理」から次の画面を開けます。</p>

<ul>
  <li><strong>履歴</strong> — 写真の閲覧・投稿・編集・削除・承認/取下げの記録</li>
  <li><strong>統計</strong> — ユーザー別の投稿数ランキング（上位 10 件）</li>
</ul>

<p>【写真履歴画面の画像】</p>

<h2>技術編</h2>

<p>以下は、システム管理者・開発者向けの技術情報です。</p>

<h4 style="border-left:3em solid black;">昆虫写真（Photos）機能</h4>

<p>昆虫写真機能は、ユーザー投稿型の画像ギャラリーです。承認ワークフロー（<code>approved_at</code>）により公開を制御し、Intervention Image でリサイズ・保存します。</p>

<h4 style="border-left:3em solid black;">機能の有効化</h4>

<p><code>.env</code> に以下を設定します。</p>

<pre><code>PHOTOS=1
</code></pre>

<p>分布情報との種写真連携には <code>INVENTORY=1</code> も必要です。画像ファイルは <code>storage/app/public/photos/</code> に保存され、<code>/storage/photos/</code> 経由で公開されます（<code>php artisan storage:link</code> 必須）。</p>

<p>写真 1 件は <code>photos</code> テーブルに保存されます。</p>

<p>種との多対多は <code>photo_speciess</code> 中間テーブル（<code>sort_order</code> 付き、最大 3 件）で管理します。</p>

<h4 style="border-left:3em solid black;">写真検索</h4>

<p><strong>一覧（SSR）:</strong> <code>GET /photos</code> — クエリ <code>keyword</code>, <code>user_id</code>, <code>place</code>, <code>date</code>。12 件/ページ。</p>

<p><strong>API（JSON）:</strong> <code>GET /photos/search</code> — 同上 + キーワードの AND 検索（photo_title, memo）。レート制限 60/分。</p>

<h4 style="border-left:3em solid black;">写真詳細 API</h4>

<p><strong>URL:</strong> <code>GET /photos/{id}/show</code></p>

<p>未ログイン時は <code>approved_at</code> がある写真のみ返却。ログイン時は未承認でも本人の写真を取得可能。プロフィール情報（<code>show_name</code>, <code>icon</code>）を JOIN して返します。</p>

<h4 style="border-left:3em solid black;">投稿・編集・削除</h4>

<h5>投稿</h5>

<p><strong>URL:</strong> <code>POST /photos/create</code>（レート制限 10/分）</p>

<p>multipart/form-data。<code>verified=1</code> 必須。<code>terms_agreed</code> 必須（accepted）。成功時 JSON <code>{result: success}</code>。管理者メール（<code>kaikon::emails.photo-create</code>）を送信。</p>

<h5>編集</h5>

<p><strong>URL:</strong> <code>POST /photos/edit</code></p>

<p>パラメータ: id, photo_title, place, date, memo。投稿者本人のみ。</p>

<h5>削除</h5>

<p><strong>URL:</strong> <code>POST /photos/delete</code></p>

<p>投稿者本人のみ。<code>photo_speciess</code> の detach、ストレージファイル削除、<code>forceDelete</code>。</p>

<h4 style="border-left:3em solid black;">承認管理</h4>

<p><strong>画面:</strong> <code>/photos/admin</code></p>

<ul>
  <li><code>POST /photos/{id}/approve</code> — <code>approved_at = now()</code></li>
  <li><code>POST /photos/{id}/unapprove</code> — <code>approved_at = null</code></li>
  <li><code>GET /photos/admin/entries</code> — ページング JSON（24 件/ページ）</li>
</ul>

<p>各操作は <code>photos_history</code> に記録（action: approve / unapprove）。</p>

<p>旧 API <code>accept</code>（承認/却下で物理削除）は deprecated です。</p>

<h4 style="border-left:3em solid black;">メタデータ CSV</h4>

<p><strong>URL:</strong> <code>GET /photos/download</code></p>

<p>カラム: id, photo_title, date, place, user, memo, created_at, updated_at</p>

<h4 style="border-left:3em solid black;">種写真 API（INVENTORY 連携）</h4>

<ul>
  <li><code>GET /species/photos/candidates</code> — 承認済み写真の検索（管理者）</li>
  <li><code>POST /species/{random_key}/photos</code> — slot_1〜3 への紐付け（管理者）</li>
</ul>

<h4 style="border-left:3em solid black;">履歴・統計</h4>

<ul>
  <li><strong>履歴:</strong> <code>/admin/history/photos</code></li>
  <li><strong>統計:</strong> <code>/admin/statistics/photos</code> — ユーザー別投稿数（上位 10）</li>
</ul>
